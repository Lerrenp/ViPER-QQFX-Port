## 1. 参数钳制全量枚举（检查项 1）

### 1.1 方法

1. **插桩复核**：monkeypatch `tools/convert_aep.py` 的 `_clamp`，对全部 51 个 `.aep`
   逐个 `build()`，记录每一次 `v≠clamp(v)` 的调用 —— 命中 **7 处**，与 dumps 内 7 条警告一一对应，**无遗漏、无多余**。
2. **独立重算**：不依赖转换器，直接 `aep_parser.parse()` 读原始 `.aep` 参数，按映射语义
   重算目标值并与 schema range 比较 —— 命中同一批 7 处，**未发现任何“生成代码静默 clamp 但 warning 缺失”**。

> 结论：**不存在缺失 warning 的范围钳制**。所有越界值都在 `convert_aep.py` 里经 `_clamp` 显式记录。

### 2.2 重点复核：id9 `ExciterEffect` 能否用 `spectrumExtension.exciter(0..6)` 表达？

结论：**不能，维持 skipped 原判**。依据：

- 全部 8 处 id9 源参数（`Frequency` / `Harmonics` / `MixBack` / `ClipBoost`）：

  | 文件 | Frequency | Harmonics | MixBack | ClipBoost |
  |---|---|---|---|---|
  | 001/002/004/009/013 | 614.4 Hz | ≈5.0 | −9…−14.2 | 0 |
  | 019-摇滚 | 778.4 Hz | 10.36 | −9.68 | 4.76 |
  | 995/997-明星 | 1916.9 Hz | 7.78 | −7.51 | 0 |

- V4A `spectrumExtension`: `strength ∈ [2200, 8200]`（激励起始频段）、`exciter ∈ [0,6]`（激励量）。
- **频段不匹配**：QQ Exciter 的 `Frequency` 为 614–1917 Hz（全在 V4A 下限 2200 之下），
  强行映射需把 614 钳到 2200（+258 %），语义已失真。
- **激励阶数不匹配**：`Harmonics` 为 5–10 阶且为小数，V4A `exciter` 是 0–6 的无量纲量，
  二者不是同一量纲，无法对应。
- 同理 V4A `clarity`（ViPERClarity，gain 0–4.5）也不匹配 `Harmonics` 阶数语义。

→ **维持原判（skipped）**，理由准确。

### 3.3 关于 4ch 内核的专门结论（重点怀疑对象）

**证据链**：`742156…` 头部 `fmt = (IEEE_FLOAT, 4, 44100, 16B blockAlign, 32-bit)`，
样本 392660 个 float / 98165 帧。逐通道统计（修复前）：

| 通道 | RMS | 峰值 | 首帧 |
|---|---|---|---|
| ch0 | 0.003254 | **1.000** | **1.0** |
| ch1 | 0.000555 | 0.070 | 0 |
| ch2 | 0.000552 | 0.070 | 0 |
| ch3 | 0.003253 | **1.000** | 0 → 但第 0 帧=**1.0**（首帧向量 `[1,0,0,1]`） |

- 相关系数：`corr(ch0,ch3)=0.996`、`corr(ch1,ch2)=0.845`、`corr(ch0,ch1)=0.155`。
- 只有 ch0 与 ch3 携带 t=0 的**直通尖峰**（峰值 1.0），ch1/ch2 无直通（峰值仅 0.07，RMS 约 ch0 的 17 %）。

→ 判定：4ch 布局为 **true-stereo 2×2 四抽头 `[LL, LR, RL, RR]`**（ch0=LL、ch1=LR、ch2=RL、ch3=RR），
交叉项能量小、无直通。V4A 卷积器是**对角**结构（`Convolver.cpp` L40-41：`kernel_ch1` 只卷 L、`kernel_ch2` 只卷 R），
无法表达输入交叉项，故 4ch 必须降为双通道。

**结论（4ch 那个 kernel）**：`742156…` 在原状态下 **app 与 DSP 两处都会被拒绝** ——
app `WavDecoder.kt` L93-95 抛 `Unsupported channel count: 4`，异常在 `ViperService.kt` L494 被吞掉，
**504-现场律动 的 convolver 实际从未生效**（README 中“V4A 卷积器按立体声下混”的旧说法与实证不符）。**已修复。**

## 4. 已实施的修复（检查项 4）

仓库内改动仅限 `kernels/441/*.wav`、`kernels/48k/*.wav`（双速率内核）与重生成的
`presets/parsed/manifest`（注：当时未 git commit，后已纳入仓库）。

### 4.1 `742156…`（504）4ch → 2ch 降混

- 取真立体声**对角声道**：`L = ch0 (LL)`、`R = ch3 (RR)`，保持 f32 / 44.1k / 98165 帧。
- 理由：直通主响应恰在对角（RMS 0.003254/0.003253，峰值 1.0）；交叉项（ch1/ch2，RMS≈0.00055）
  V4A 对角卷积器本就不能表达，丢弃后仅损失约 2 % RMS 能量与侧向串馈色彩。
- 校验：新文件 `(IEEE_FLOAT, 2ch, 44100, 32-bit)`，逐通道 RMS 与源 ch0/ch3 **完全一致**，峰值 1.0。

### 4.2 `fae6b7a7…`（018）48 kHz/24bit → 44.1 kHz/float32

- 频率比 48000→44100，用 numpy 频域重采样（`irfft(rfft(x))` 截断/补零 + `M/N` 增益），
  2130 帧 → 1957 帧，时长保持 0.044375 s。
- 位深 24→32f（app/DSP 均支持 24bit，此处随重采样一并规范化为内核标准格式）。
- 校验：新文件 `(IEEE_FLOAT, 2ch, 44100, 32-bit)`；RMS 0.03665→0.03527（−3.8 %，重采样正常损耗），
  峰值 1.0→1.049（频域重采样的轻微 Gibbs 过冲，对 IR 可接受）。
- 假设与备选：DSP 无内核重采样，内核被假定与管线同率；`constants.h` 默认 44.1k 且 13/14 内核为 44.1k，
  故统一到 44.1k。若目标机管线确为 48 kHz，应改用 `极重低音_48k.wav`
  （现仓库已同时提供 441/48k 双版本，无需再手工恢复）。

## 5. 结论：各预设保真度分级

### 5.1 无损映射（无钳制、无跳过节点、语义精确）

- **500-全景环绕**（旧版）、**500-全景环绕.new**：除 diffSurround delay 钳制外全部 verified；
  EQ/Q 已披露。**带 1 处明显钳制**（delay）。
- **504-现场律动**：verified 主体 + approx(convolver/reverb) + 1 处明显钳制（delay）。修复 4ch 内核后 convolver 才真正生效。

> 严格意义的“完全无损”预设：**无**。`verified 2` 的两个 500 也各带 1 处 delay 钳制。

### 5.2 带轻微近似

- **014-留声机**：仅 outputVolume −1.60 dB 钳制（轻微），另含 3 个 skipped 节点（BPFilter、2×Sampler）。

### 5.3 带明显近似

- **065-智能伴奏**：两个 id51 频段各 +7 dB 削减不足（明显），另含 MusicSeparation skipped。
- **500 / 500.new / 504**：diffSurround delay −6.12 ms（明显）。
- **008-小编制**：id24 最低频段 16→20 Hz（无感）+ convolver/dynamicEq 结构近似。
- 12 个 `[63]` 房间/空间系列（050-061）：MVerb→Freeverb 结构近似，6 个参数无对应（已披露）。
- 001/007/009/010/011/012/013/015/017/018：convolver 命中，属 approx；其中 012 另有两段串联塌缩（§1.3）。
- 其余 partial（002/016/019/020/996/997/998 等）：含 skipped 节点，按 manifest 标注。

### 5.4 风险与遗留

1. **048 内核采样率**为推断结论（DSP 无重采样）；若目标设备管线为 48 kHz，应改用原 48k 内核。
2. **4ch 降混**按 true-stereo `[LL,LR,RL,RR]` 认定，取对角声道；若 QQ 实际布局为其他 4 声道语义，
   下混结果会不同（已用逐通道 RMS/直通尖峰/相关矩阵给出认定依据）。
3. **012 串联卷积塌缩**为 V4A 单卷积器固有限制，无法在不改预设结构的前提下修复；当前仅保留末个内核且未告警，
   属可改进项（建议在 `convert_aep.py` 为“多次 id2 覆盖”补一条 warning，本次未改转换逻辑以遵守范围约束）。
4. `复合低音_备选`（原 `b7c9156c…`）、`采样素材_黑胶_留声机`（原 `679a…`）、
   `采样素材_黑胶_留声机_2`（原 `de36ef…`）三个内核未被任何生效预设使用
   （第一个因 012 单卷积器被覆盖，后两者为 id7 采样素材而非卷积核），保留在 `kernels/441|48k/` 备查。
